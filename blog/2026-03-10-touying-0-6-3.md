Touying 0.6.3 is a major bugfix release that also brings a batch of practical new features, most of them around animations and handout mode.

<!-- truncate -->

## What's New

- **`#jump` as unified animation control**: `#jump(n, relative: false)` is the new primitive for moving the subslide counter, and `#pause` and `#meanwhile` are now sugar on top of it. `#jump(3)` skips straight to subslide 3.
- **`#item-by-item`** reveals a list, enum or terms block one item at a time ([#278](https://github.com/touying-typ/touying/pull/278)):

```typst
#item-by-item[
  - First
  - Second
  - Third
]
```

- **`#touying-raw`** reveals a code block progressively, splitting on a `pause` comment in the code itself ([#283](https://github.com/touying-typ/touying/pull/283)):

```typst
#touying-raw(```rust
fn main() {
    // pause
    println!("Hello, world!");
}
```)
```

- **Handout mode, more precisely**: `#handout-only[..]` marks inline content as handout-exclusive and the `<touying:handout>` label does the same for a whole slide ([#286](https://github.com/touying-typ/touying/pull/286)), while `handout-subslides` picks which subslides survive ([#288](https://github.com/touying-typ/touying/pull/288)).
- **Speaker notes and aspect ratios**: a full-screen notes mode with a slide thumbnail via `show-only-notes` ([#281](https://github.com/touying-typ/touying/pull/281)), and arbitrary aspect ratios such as 16-10 across all themes ([#280](https://github.com/touying-typ/touying/pull/280)).
- Also: a `subslide` parameter for `#touying-recall` ([#285](https://github.com/touying-typ/touying/pull/285)), `default-composer` in `config-common` for a global slide layout ([#284](https://github.com/touying-typ/touying/pull/284)), a `cover-fn` parameter on `uncover` for packages like Fletcher ([#267](https://github.com/touying-typ/touying/pull/267)), and inline minislides ([#228](https://github.com/touying-typ/touying/pull/228)).

## Fixes

Many long-standing bugs are gone: ghost blank slides from a `touying-set-config` anchor regression, styled content on the first slide creating extra slides, `#meanwhile` being ignored inside grid cells and boxes, the `config:` parameter being silently ignored across all themes, and slides after `#show`/`#set` rules not rendering. See the [Changelog](/docs/changelog) for the full list.

## For theme authors

Move `config` to the **last** position in `utils.merge-dicts` so user overrides win, and replace `paper` with `utils.page-args-from-aspect-ratio` to support arbitrary aspect ratios:

```typst
self = utils.merge-dicts(self, config-page(..utils.page-args-from-aspect-ratio(aspect-ratio), ...), config)
```

The documentation website was also substantially restructured in this release, with a new references page and docstrings across all source files.
