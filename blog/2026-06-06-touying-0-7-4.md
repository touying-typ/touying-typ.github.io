Touying 0.7.4 adds on-slide navigation arrows, easier integration with external packages, and a batch of fixes around warnings.

<!-- truncate -->

## What's New

- **`lr-navigation`**: a navigation element with links to the previous and next subslide or slide, plus a centre icon ([#352](https://github.com/touying-typ/touying/pull/352)). Put it in a footer and the arrows become clickable links in the exported PDF; `mode` chooses between `"subslide"`, `"page"` and `"both"`, and `show-useless: false` hides links that would go nowhere. You can choose custom icons.

```typst
#lr-navigation(mode: "both", show-useless: false)
```

- **`touying-reduce`**: automatically looks up reducer bindings for a given package ([#363](https://github.com/touying-typ/touying/pull/363)), so integrating an external package's functions with Touying's animations takes less setup.
- **`components.full-width-block`**: a block that spans the full page width by cancelling the horizontal margins.
- **`lazy-layout`** gained a `grid-size` parameter for quantized position grouping, making column and row detection more robust.
- **Polish locale** for the outline message ([#372](https://github.com/touying-typ/touying/pull/372)).

## Fixes

- *Minor breaking change*: the `lazy-layout` parameter of `cols` now defaults to `false` instead of `true`, so columns are no longer height-equalised unless you ask.
- `hide` no longer does unexpected things to headings ([#366](https://github.com/touying-typ/touying/pull/366)).
- `touying-fn-wrapper-raw` is now exported as part of the public API ([#362](https://github.com/touying-typ/touying/pull/362)).
- Mark warnings are improved and are also shown as `magic.warning` when `enable-mark-warning` is `false` ([#348](https://github.com/touying-typ/touying/pull/348)); a missing `fn` field in a mark warning message is handled gracefully.
- Warnings are now emitted via `uniwarn` ([#359](https://github.com/touying-typ/touying/pull/359)).
