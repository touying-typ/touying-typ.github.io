Touying 0.7.3 fixes a long-standing speaker-note pitfall — at the cost of two small breaking changes — and adds more control over item-by-item animations and progressive outlines.

<!-- truncate -->

## Minor Breaking Changes

**`#speaker-note[]` now always attaches to the slide above it** ([#354](https://github.com/touying-typ/touying/pull/354)), no matter how that slide was created: an explicit slide call, a heading-triggered section slide, or a normal content slide. This gets rid of the common pitfall where a `#speaker-note[]` placed after a slide silently created an unwanted empty "ghost" slide.

Along with it, `receive-body-for-new-section-slide-fn` and its variants now default to **`false`** (previously `true`). If you relied on content after a `= Section` heading being absorbed into the section slide body, set it explicitly:

```typst
#import "@preview/touying:0.7.3": *
#import themes.university: *

#show: university-theme.with(
  config-common(receive-body-for-new-section-slide-fn: true),
)
```

## What's New

- **`item-by-item-fn`** and presets for it ([#347](https://github.com/touying-typ/touying/pull/347)).
- **Progressive outlines**: `custom-progressive-outline` was improved, and there is a new `section-relationship` ([#345](https://github.com/touying-typ/touying/pull/345)).
- **`cols`**: a new alias of `side-by-side`, with `cols` and the `lazy-*` components now exported ([#356](https://github.com/touying-typ/touying/pull/356)). `lazy-layout` also handles mixed layouts better ([#355](https://github.com/touying-typ/touying/pull/355)).
- **Metropolis** gained an outline slide ([#349](https://github.com/touying-typ/touying/pull/349)).
- A warning is now emitted when an empty slide content height is detected.
